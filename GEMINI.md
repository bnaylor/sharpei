# Agent Instructions

## Issue Management
- NEVER close a GitHub issue without explicit confirmation from the user that the fix is validated.
- When closing an issue, always include a comment linking the final fix to its specific commit hash (e.g., "Fixed in commit [hash]").

## Version Control
- Always include co-author attribution for Gemini in commit trailers:
  `Co-authored-by: Gemini <gemini-cli@google.com>`
